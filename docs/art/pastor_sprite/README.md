# Hauptfigur (Pastor) – Sprite-Vorlage

Quelle: Kenney „RPG Urban Pack“ (CC0), `assets/images/kenney/rpg_urban_pack/tilemap_packed.png`,
Figur 2 (Ausschnitt x 368–431, y 96–143).

- `pastor_sheet_16px.png` – **Originalgröße, genau dieses Format liest das Spiel**:
  64 × 48 px, 4 Spalten × 3 Zeilen, je 16 × 16 px, transparenter Hintergrund.
  - Spalten (Blickrichtung): links · unten · oben · rechts
  - Zeilen: stehen · laufen 1 · laufen 2
- `pastor_sheet_preview_10x.png` – 10× vergrößert mit Raster und Beschriftung (nur zum Ansehen).
- `pastor_front_16x.png` – die Vorderansicht (stehend) 16× vergrößert.

Für einen Heilsarmee-Offizier bitte dieselbe Aufteilung (64 × 48 px, 16 × 16 pro Bild,
PNG mit Transparenz) zurückgeben – dann kann sie direkt eingebaut werden.
